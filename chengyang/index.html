    ABOUT THE LIBRARY

    关于这个学习索引

    为什么建立？

    现场电工短视频常按时间流展示，不便按故障查找。这里按跳闸、漏电触电、零线与接地、电压异常、照明插座、电机设备和仪表等分类，方便“带着问题找案例”。

    目前仅包含已核验的部分公开作品，并非作者全部视频；视频数量以页面当前数据为准。后续补齐需要进一步核实完整公开目录。

    版权与安全

    本站是非官方学习索引，不下载、不重新托管或改编作者视频；标题与原链接用于指引用户前往源平台学习。本站不附会具体维修原因，不保证每条视频展示的操作适用于其他场景。

    如权利人希望纠正署名或移除索引，可通过网站所在 GitHub 仓库的 Issue 提交请求。

    学习记录、笔记和个人导入的视频数据仅存浏览器本地；清除浏览器数据后可能丢失。
