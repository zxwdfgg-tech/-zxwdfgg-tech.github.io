# 智维实训（中文交互版）

面向数据中心、配电室 MCC、UPS 与柴油发电机的离线交互培训原型，共 24 关：

- AI 数据中心：8 关
- MCC 配电室：8 关
- UPS 与柴油发电机：8 关

进入 `index.html` 开始，支持手机和电脑，支持浏览器离线 PWA 安装。本软件为独立制作的2.5D逻辑仿真练习，不包含原站的3D模型或私有源代码。不应用于现场操作或取代企业的真实安全操作票、规程、隔离措施和持证培训。

许可证：MIT。见仓库 idc-lab/LICENSE。

Android APK 使用仓库内 `idc-android/` 项目打包，首次构建完成后从 GitHub Actions / Releases 下载。
